# Project README: Screen Time, Productivity, and Demographics Analysis

This project explores how screen time correlates with demographic factors, productivity, and attention span using exploratory data analysis (EDA) and ordinal logistic regression modeling.

---

## 1. Installation & Environment Setup

### Prerequisites
* **Python**: Python 3.8 or higher.
* **Dataset**: `data.csv` must be located in the same directory as the script files.

### Required Libraries
Install all required dependencies using `pip`:

```bash
pip install pandas plotly scikit-learn mord
